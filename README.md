本作品针对商场日常宣传、寻人寻物及突发事件信息发布需求，设计实现 “商安视界・商场宣传与应急终端”。系统以安路 EG4S20 FPGA 为核心，搭配 Windows 上位机，集成广告轮播、音视频播放、临时通知、应急提示等功能，统筹各类硬件资源，完成多业务切换与恢复。 上位机负责素材制作、排版与播放控制，FPGA 承担媒体读取、解码、画面合成及音画输出。为适配有限内存，系统采用专属存储、环形缓冲等优化技术保障播放稳定，通知字模经传输校验后发布。 系统依托场景优先级分配资源，支持通知叠加、应急全权接管设备，险情解除后可自动还原原有播放状态与参数。经实机验证，系统各项核心功能均可正常运行，成功实现有限硬件条件下商场宣传、便民通知与应急业务的一体化智能管理。及四类应急提示。
